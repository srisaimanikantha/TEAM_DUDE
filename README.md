## 🎯 How It Works

1. 📌 **Daily Task Assignment** — Manikantha assigns a fresh task to each member every day.
2. 💻 **Solve in Java** — Members write clean, working Java solutions for the day's task.
3. 📤 **Daily Push** — Push your solution to your designated folder before the day ends — no skipping!
4. 🔍 **Review** — Shashank Sir reviews the code and provides feedback.
5. 🔁 **Iterate** — Apply feedback, refactor, and carry the lesson into tomorrow's task.
6. 🚀 **Level Up** — One task a day keeps the rust away!

- 📈 **Progress over perfection** — messy first drafts are welcome, growth is the goal.
