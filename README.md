# 🏁 THE DUDE CHALLENGE

Every Java concept we learn should pass the **3D Test**:

### 1️⃣ DEFINE

**Do I know what it means?**

### 2️⃣ DO

**Can I write it myself?**

### 3️⃣ DEBUG

**Can I find and fix mistakes in it?**

If the answer is **YES → DUDE LEVEL UP 🔥**
